# 项目愿景

## 我们想解决的问题

人在经历一段关系时，通常同时拥有事实、感受、解释、期待、记忆偏差和事后认识。它们纠缠在一起，使人很难回答：到底发生了什么，我为何如此反应，这段经历改变了什么？

这个项目希望建立一种温和但严谨的方法，让人能够：

- 保存经历，而不是只留下事后的简单结论；
- 区分可观察事实、个人解释、情绪与需要；
- 看见反复出现的关系模式，又不急于给人贴标签；
- 容纳同一段经历中的矛盾与视角变化；
- 把理解转化为具有生命感的叙事。

## 第一套样本

作者自己的经历与思考是第一套长期样本。选择个人样本有三个原因：

1. 作者能够持续补充背景、纠正误读；
2. 同一件事可以被不同年龄阶段重新解释；
3. 分析框架能在真实、复杂且不完美的材料中接受检验。

个人样本不是普遍规律。每当从个人经验中抽象出一个方法时，都应追问：

- 它依赖哪些具体背景？
- 在什么情况下可能不成立？
- 它是在帮助理解，还是只是在美化事后解释？
- 其他人使用它时，会不会受到误导或伤害？

## 面向他人的价值

成熟后的项目不负责替用户裁决谁对谁错，而是提供一组能够推动理解的问题、记录方式和叙事工具。理想情况下，使用者能得到三类结果：

- 一份更清楚的关系事件记录；
- 一张展示情绪、需要、行动与后果的思考地图；
- 一篇保留个人声音的自传式反思文章。

## 最终作品形态

最终长文采用“双线结构”：

- **时间线**承载人生经历、人物、场景和变化；
- **主题线**讨论关系、亲密、羞耻、期待、边界、失去、选择和成长等问题。

主题线不应凌驾于故事之上。它应当从具体经历中自然生长，并允许作者承认自己仍然没有答案。

## 成功标准

这个项目的成功不以理论数量衡量，而以以下标准衡量：

- 作者读到文字时，认为它真实表达了自己的变化；
- 框架能容纳复杂性，而不是快速生产结论；
- 他人可以使用框架提出更好的问题；
- 最终作品既能作为个人生命记录，也能给读者带来可迁移的启发。
