# 自动录入归一化（Docling 转换适配器）

转换是后端录入流程的内部步骤，用户无需选择转换器、运行命令或点击“转换”。Arrive 直接调用 `docling-slim` 的 Python 转换接口，不启动 Docling 服务、不嵌入其 UI，也不调用 Docling CLI。只声明已接入格式及本地模型所需的依赖；普通文本直接按 UTF-8 写为 Markdown。

## 实际流程

1. `POST /api/v1/materials` 保存原话，同时在同一数据库事务中创建归一化任务。正文按原字符串保存为 `.md`，不改写内容。
2. `POST /api/v1/sources` 登记网页来源，同时自动创建抓取/转换任务；若提供已归档的 `raw_archive_path`，处理该原件。纯文件来源允许 `original_url: null`，无需伪造网址。
3. `POST /api/v1/source-files?filename=example.pdf&title=Example` 接收文件原始字节作为请求体，先保存原件和接收记录，再登记来源并入队。这是录入接口，不是转换按钮接口；当前不是 multipart 格式。
4. 后端启动时自动启动单个后台工作线程，处理持久化任务。下载或模型加载不阻塞录入请求；任务结果为 `converted`、`needs_review` 或 `failed`。
5. Markdown、Docling JSON（有页码/坐标时保留）与原件都留在 `ARRIVE_DATA_DIR`。提取不形成个人认同，不将来源文字当作个人素材或已确认地图节点。

`GET /api/v1/documents/{owner_id}` 返回处理状态和文件键；`GET /api/v1/documents/{owner_id}/{job_id}/markdown` 返回已保存文本，尚无结果时返回 409。其他后端流程可直接调用 `enqueue`/读取 `DocumentJob`，不用经过命令行。

## 安装与运行

项目根目录：`python -m pip install -e ./backend`，然后按后端 README 启动。转换依赖已成为默认依赖，`[documents]` 仅为旧命令保留的兼容别名。`requirements.lock` 已更新 Linux Python 3.12 哈希锁，Docker 安装同一套后端依赖并包含 OCR 原生库；容器构建仍未验收。

单个数据根只允许一个后端进程运行工作线程，文件锁会拒绝第二个实例。启动自动恢复 `running` 状态的中断任务；已完成任务不重复转换。失败任务保留状态和原件，本轮未实现自动重试策略或管理重试 API。正常关闭等待线程最多两秒；正在处理的任务可能在进程退出时中断，下次启动恢复。处理状态是可更新的队列状态；原件、提取运行记录和观点事件不被覆盖。

## 保存与边界

- 文件接收原件：`raw/sources/uploads/<uuid>/`，包含带时区时间和 SHA-256 的接收记录；中断上传明确标为不完整。
- 来源快照：`raw/sources/SRC-NNNN/VNNN/`。自动分配未使用的快照目录，保留开始、获取成功/失败记录及原始字节。
- 转换结果：`sources/extractions/SRC-NNNN/VNNN/<run-id>/document.md`、`document.json` 和 `result.json`。
- 直接文本副本：`outputs/normalized/MNNN/<uuid>.md`，权威原话仍在素材记录中。

新任务与来源/素材一起提交，上传原件先于数据库记录保存；数据库失败时原件可能成为待人工恢复的未关联档案，不自动删除。旧来源不会因升级被批量重新抓取。旧版本任务与快照仍可回看。

支持 PDF、HTML、DOCX、PPTX、XLSX、TXT、MD、PNG、JPEG、TIFF。UTF-8 文本原样写出；其他编码文件保留原件并报告失败，不猜测编码。PDF/图片使用 RapidOCR 中文模型和 PyPdfium 后端，模型首次使用可能联网下载；不启用云端模型服务。可预取模型，见 [Docling 模型说明](https://docling-project.github.io/docling/usage/advanced_options/)。

网页只保存 HTTP 响应，不执行脚本、不递归抓图片或链接，不承诺完整网站镜像。登录/反爬页面可能返回 200，抓取成功不是内容准确性认证。后端拒绝解析为本地/私网地址的 URL，并检查重定向目标；此检查不是抵御恶意 DNS 变化的完整网络沙箱，服务仍限本地或受控环境。输入上限 100 MiB，网络读取超时 30 秒。OCR、表格、脚注和阅读顺序均可能出错，成功的提取结果仍标为待核对，原件不可被提取结果替代。
