# 路线图

## v0.x：个人写作实验室

目标：建立稳定的素材收集和复盘习惯，用真实经历检验分析框架。

- [x] 建立长文写作协作机制
- [x] 建立第一版仓库结构
- [x] 建立经历、分析、主题和章节模板
- [ ] 记录第一批原始想法
- [ ] 整理至少 5 个具体经历
- [ ] 建立第一张主题关系图
- [ ] 根据使用体验修订分析框架至 v0.2

阶段产物：个人素材库、首批主题档案、框架修订记录。

## v1.x：形成可复用的方法

目标：从个人样本中提炼能够被他人理解和使用的方法，同时明确适用边界。

- [ ] 整理核心问题集
- [ ] 为不同类型的关系事件设计分析路径
- [ ] 增加反例和失败案例
- [ ] 建立匿名化与发布检查清单
- [ ] 邀请少量使用者试用并收集反馈

阶段产物：感情分析手册、示例库、隐私规范和反馈记录。

## v2.x：生成个人长文

目标：以时间线和主题线组织个人素材，完成可持续修订的书稿。

- [ ] 确定全书核心问题
- [ ] 建立人生时间线和主题索引
- [ ] 设计章节结构
- [ ] 完成关键章节试写
- [ ] 完成第一版全稿
- [ ] 进行事实、隐私、逻辑和语言审校

阶段产物：一部自传式叙事与思考长文。

## v3.x：面向他人的项目

目标：把已经验证的部分转化为其他人也能使用的产品。

可能形态包括交互式写作助手、问题卡、工作手册或网站。具体形态应根据前几个阶段的真实需求决定，不预先锁定。

- [ ] 明确目标使用者和使用场景
- [ ] 分离个人样本与通用框架
- [ ] 设计安全边界与危机提示
- [ ] 制作最小可用原型
- [ ] 评估输出是否真实、有帮助且不过度推断

阶段产物：经过真实使用验证的感情分析与叙事工具。

## 近期下一步

1. 在 `content/inbox/` 中记录第一批未经整理的想法。
2. 选择一个记忆清晰的事件，使用 `templates/经历记录.md` 整理。
3. 使用 `templates/关系分析.md` 完成第一次分析。
4. 记录哪些问题有帮助、哪些问题不自然，据此修订框架。
