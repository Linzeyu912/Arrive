# 观点回应时间线

这里记录使用者在不同时间对来源观点和个人命题的回应。

## 为什么使用时间线

观点不是个人永久不变的属性。同一个人在不同经历、关系阶段和人生时期，可能对同一句话产生完全不同的感受和判断。

因此，本项目不只记录“现在是否认同”，还记录：

- 在什么时间产生了这次回应；
- 当时喜欢、认同或准备采用的分别是什么；
- 这一判断处于怎样的生活和思考语境；
- 它与此前状态有什么变化；
- 后来的自己如何看待当时的判断。

## 三条独立轴

### 共鸣 `resonance`

回答“这句话是否打动我、像我、或者让我觉得表达得很好”。

可用值：

- `high`
- `medium`
- `low`
- `none`
- `unspecified`

产生共鸣不等于认为观点正确。可以喜欢一句话的表达，但不同意它的结论。

### 认同 `agreement`

回答“我目前是否接受这个判断”。

可用值：

- `agree`
- `mostly_agree`
- `partly_agree`
- `uncertain`
- `disagree`
- `unspecified`

### 采用 `adoption`

回答“我是否愿意把它纳入自己的思考或表达”。

可用值：

- `adopt`：作为自己的当前观点；
- `adapt`：经过修改后纳入自己的观点；
- `cite`：只作为外部观点引用；
- `not_use`：不进入自己的表达；
- `undecided`：尚未决定。

## 时间字段

每条回应事件必须包含：

- `recorded_at`：实际记录时间，使用带时区的 ISO 8601 格式；
- `effective_at`：这个想法实际属于哪个时间点；通常与记录时间相同，回忆过去观点时可以不同；
- `time_precision`：时间精度，使用 `minute`、`day`、`month`、`year` 或 `unknown`；
- `context`：促成这次判断的经历、关系阶段或阅读语境；不清楚时写 `pending`，不能猜测。

示例：

```yaml
event_id: RSP-20260904-001
target: SRC-0001/P04
recorded_at: 2026-09-04T11:17:38+08:00
effective_at: 2026-09-04T11:17:38+08:00
time_precision: minute
resonance: high
agreement: partly_agree
adoption: adapt
confidence: medium
supersedes: null
```

## 追加而不覆盖

回应事件建立后不通过改写旧事件来制造“我一直如此”的假象。

观点发生变化时，新增一条事件，并在 `supersedes` 中引用上一条相关事件。旧观点即使已经不再认同，也继续保留，因为它记录了思考变化的路径。

若旧事件记录有事实性错误，新增 `correction` 事件说明错误和修正，不静默删除历史记录。

## 编号

回应事件使用：

```text
RSP-YYYYMMDD-NNN
```

同一天按记录顺序递增。来源观点继续使用 `SRC-NNNN/PNN`；使用者正式采用后，再建立个人命题 `PNNN`，并在事件中记录二者关系。

## 当前立场

“当前立场”是截至某个时间点，从回应事件推导出的快照，不是唯一历史。任何当前状态都必须注明 `as_of`。

需要回看变化时，优先展示时间线，而不是只展示最新结论。
