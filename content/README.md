# 内容库

这里保存项目的个人样本与主题材料。

## 目录

- `inbox/`：未经整理的快速记录；
- `experiences/`：按事件整理的经历；
- `reflections/`：不依附于单一事件的思考；
- `themes/`：跨越多个事件的主题档案；
- `private/`：高敏感原始材料，已被 Git 忽略。

## 命名约定

经历文件：

```text
E-YYYYMMDD-NNN-简短标题.md
```

思考文件：

```text
R-YYYYMMDD-NNN-简短标题.md
```

日期未知时可以使用 `unknown`，例如：

```text
E-unknown-001-一次没有说完的告别.md
```

编号创建后保持不变。文件标题可以随着理解变化而修改。

## 内容流转

```text
inbox → experiences / reflections → themes → manuscript
```

流转不等于删除。原始素材应尽量保留，后续解释以新的记录追加，以便看见作者认识变化的过程。

## 隐私

每份结构化材料都需要填写 `privacy`：

- `private`：不得进入书稿；
- `anonymized`：只有匿名化版本可以进入书稿；
- `publishable`：经过作者确认，可以公开。

如果内容包含极高敏感信息，请放入本地的 `content/private/`，不要提交到 GitHub。
