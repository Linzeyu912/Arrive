# 内容与样本库

这里保存用于验证“抵达”框架的真实思绪、思考地图和转译样本。

## 目录

- `inbox/`：未经整理的快速输入；
- `samples/`：完成过一次或多次转译的样本；
- `maps/`：由素材形成的思考地图；
- `private/`：不得上传的高敏感材料，已被 Git 忽略。

## 命名

原始输入：

```text
M-YYYYMMDD-NNN-简短标题.md
```

转译样本：

```text
T-YYYYMMDD-NNN-简短标题.md
```

日期未知时使用 `unknown`。编号建立后保持稳定，标题可以随着理解变化而修改。

## 隐私等级

- `private`：只用于本人理解，不进入可分享输出；
- `anonymized`：匿名化后可以进入样本或输出；
- `shareable`：表达者已经确认可以分享。

原始记录应尽量保留。后续认识发生变化时，以新版本或补充记录呈现，不要把过去的自己改写成从一开始就知道答案。
