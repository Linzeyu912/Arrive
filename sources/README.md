# 外部来源库

这里保存对外部思想来源的可追溯记录，包括网络文章、书籍、视频、播客、演讲和对话。

“保存来源”包含两层：

1. **完整保存来源身份**：原始链接、作者、标题、平台、发布时间、访问日期、版本线索和处理记录；
2. **保存可复用的思想内容**：文章结构、详细摘要、关键命题、概念关系、必要短摘以及使用者对它的认同或质疑。

对于受版权保护的第三方内容，仓库不保存未经许可的全文副本。来源记录必须保留可追溯链接，并用自己的话进行摘要；直接摘录只保留论证所必需的短片段。

## 目录

- `web/`：网页和微信公众号文章；
- `books/`：书籍和长篇出版物；
- `media/`：视频、播客和演讲；
- `INDEX.md`：全部来源的统一索引。

## 来源编号

来源使用稳定编号：

```text
SRC-0001
SRC-0002
```

编号分配后不重新排序。文件名采用：

```text
SRC-0001-简短标题.md
```

标题尚未取得时使用平台或临时说明，待补全后可以修改文件名，但编号保持不变。

## 分类维度

每条来源同时从以下维度分类：

### 内容载体 `source_kind`

- `web_article`
- `book`
- `video`
- `podcast`
- `speech`
- `conversation`
- `other`

### 来源关系 `stance`

- `pending`：使用者尚未表明态度；
- `endorsed`：认同来源的核心观点；
- `partially_endorsed`：认同其中一部分；
- `reference`：用作资料，不代表认同；
- `questioned`：主要用于质疑或反思；
- `opposed`：明确反对其核心观点。

来源作者的观点与使用者本人的观点必须分别保存。只有标记为 `endorsed` 或由使用者明确确认的命题，才能被记录为“使用者认同”；即便如此，引用时仍需注明原作者。

### 处理状态 `content_status`

- `registered`：只完成来源登记；
- `metadata_only`：已获得基本元数据；
- `summarized`：已完成结构与内容摘要；
- `mapped`：已提取命题并连接到思考地图；
- `cited`：已经进入某份表达成品；
- `unavailable`：当前无法读取。

### 权利状态 `rights`

- `third_party_copyright`：第三方受版权保护内容；
- `licensed`：获得明确许可的内容；
- `public_domain`：公有领域内容；
- `user_owned`：由使用者拥有版权的内容；
- `unknown`：尚未确认。

## 网络来源采集流程

1. 登记原始 URL 和访问日期；
2. 确认最终 URL、标题、作者、平台和发布日期；
3. 识别来源载体、语言和初步主题；
4. 保存文章结构和详细摘要；
5. 提取关键命题、论据、反例和概念关系；
6. 保存总量有限、确有必要的短摘；
7. 请使用者标记认同、部分认同、引用、质疑或反对；
8. 将已确认的命题连接到个人思考地图；
9. 记录抓取失败、页面变化或链接失效情况。

网页读取失败时，不猜测标题、作者或主要观点。先以 `unavailable` 或 `registered` 状态保存，后续通过合法可访问的页面、作者授权副本或使用者提供的内容补全。
