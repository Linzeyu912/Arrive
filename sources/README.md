# 外部来源库

这里保存对外部思想来源的可追溯记录，包括网络文章、书籍、视频、播客、演讲和对话。

“保存来源”包含三个层次：

1. **原始档案层**：在权利允许或使用者直接提供时，本地保存原始内容并计算哈希；
2. **来源身份层**：保存原始链接、作者、标题、平台、发布时间、访问日期、版本线索和处理记录；
3. **思想转译层**：保存文章结构、详细摘要、关键命题、概念关系、必要短摘以及使用者对它的认同或质疑。

对于受版权保护的第三方内容，GitHub 仓库不保存未经许可的全文副本。使用者直接提供的全文可以作为本地私密档案放入 `content/private/sources/`，该目录不受 Git 跟踪；仓库只提交来源记录、摘要和必要短摘。获得授权、公有领域或使用者拥有版权的材料可以根据其权利状态另行处理。

## 两地保存原则

```text
本地私密目录（不提交）
└── 用户提供或有权保存的原始全文
    └── 记录字节数与 SHA-256

GitHub 仓库（可版本管理）
└── 来源卡
    ├── 元数据与链接
    ├── 分类与处理状态
    ├── 详细摘要与文章结构
    ├── 原作者命题与协作者分析
    └── 使用者认同、质疑与引用关系
```

这种方式既保留原始依据，也避免把第三方全文作为项目内容重新发布。

## 目录

- `web/`：网页和微信公众号文章；
- `books/`：书籍和长篇出版物；
- `media/`：视频、播客和演讲；
- `INDEX.md`：全部来源的统一索引。

## 来源编号

来源使用稳定编号：

```text
SRC-0001
SRC-0002
```

编号分配后不重新排序。文件名采用：

```text
SRC-0001-简短标题.md
```

标题尚未取得时使用平台或临时说明，待补全后可以修改文件名，但编号保持不变。

## 分类维度

每条来源同时从以下维度分类：

### 内容载体 `source_kind`

- `web_article`
- `book`
- `video`
- `podcast`
- `speech`
- `conversation`
- `other`

### 来源关系 `stance`

- `pending`：使用者尚未表明态度；
- `endorsed`：认同来源的核心观点；
- `partially_endorsed`：认同其中一部分；
- `reference`：用作资料，不代表认同；
- `questioned`：主要用于质疑或反思；
- `opposed`：明确反对其核心观点。

来源作者的观点与使用者本人的观点必须分别保存。只有标记为 `endorsed` 或由使用者明确确认的命题，才能被记录为“使用者认同”；即便如此，引用时仍需注明原作者。

### 处理状态 `content_status`

- `registered`：只完成来源登记；
- `metadata_only`：已获得基本元数据；
- `summarized`：已完成结构与内容摘要；
- `mapped`：已提取命题并连接到思考地图；
- `cited`：已经进入某份表达成品；
- `unavailable`：当前无法读取。

### 权利状态 `rights`

- `third_party_copyright`：第三方受版权保护内容；
- `licensed`：获得明确许可的内容；
- `public_domain`：公有领域内容；
- `user_owned`：由使用者拥有版权的内容；
- `unknown`：尚未确认。

## 网络来源采集流程

1. 登记原始 URL 和访问日期；
2. 优先使用合规的页面读取工具获取元数据和主要内容；
3. 页面不可读取时，可以尝试正常浏览器访问或搜索合法转载，不绕过验证码、付费墙或安全限制；
4. 使用者直接提供内容时，将完整文本保存到本地私密目录并记录来源方式与文件哈希；
5. 确认最终 URL、标题、作者、平台和发布日期；
6. 识别来源载体、语言和初步主题；
7. 保存文章结构和详细摘要；
8. 提取关键命题、论据、反例和概念关系；
9. 保存总量有限、确有必要的短摘；
10. 请使用者标记认同、部分认同、引用、质疑或反对；
11. 将已确认的来源命题转化为个人命题，并连接到思考地图；
12. 记录抓取失败、页面变化或链接失效情况。

## 命题归属

来源内部的命题使用以下格式：

```text
SRC-0001/P01
SRC-0001/P02
```

这些编号只表示“协作者认为原作者提出了这个观点”，不表示使用者认同。使用者明确确认后，才为其建立独立的个人命题编号，例如 `P012`，并记录它来自或受到了哪个来源命题的影响。

需要同时保留三个层次：

- **原作者观点**：来源实际提出了什么；
- **协作者分析**：我们如何概括、连接或质疑它；
- **使用者立场**：认同、部分认同、引用、质疑或反对。

## 引用规范

- 引用任何外部观点时注明作者；作者未知时注明标题、平台和链接；
- 不把“用户提供了来源”写成“用户认同该观点”；
- 转述必须保持原观点的限定条件，不为方便论证而扩大结论；
- 直接摘录保持在必要的最短范围；
- 正式发表前重新检查链接、署名、发布时间和原文语境；
- 无法确认作者或出处的内容不得伪装成权威引用。

网页读取失败时，不猜测标题、作者或主要观点。先以 `unavailable` 或 `registered` 状态保存，后续通过合法可访问的页面、作者授权副本或使用者提供的内容补全。
