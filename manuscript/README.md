# 书稿

这里保存由素材库生成的自传式叙事与思考长文。

建议结构：

```text
manuscript/
├── outline.md       # 当前全书结构
├── chapters/        # 分章草稿
├── full-draft.md    # 合并后的完整草稿
└── changelog.md     # 重要结构和观点变化
```

写入书稿前，应检查所引用素材的隐私等级。`private` 素材不得进入书稿；`anonymized` 素材必须完成匿名化后才能使用。

书稿可以重组经历以形成清晰叙事，但不得为了戏剧效果虚构关键事实。若对时间、原话或动机不确定，应在工作稿中明确标记。
